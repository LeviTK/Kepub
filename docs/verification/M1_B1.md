# M1-B1 / P1 只读导航与引用验证

日期：2026-10-05（Asia/Shanghai）。执行环境：独立 Ultra orb，Linux amd64，`go version go1.27.1 linux/amd64`。共同基线由父线程传入 Git bundle，导入并确认其 `main` 为 `54e49b30d26d06de530d37166a104b00accb8344`，而不是文档阶段的 `origin/main`。工作分支：`m1-b1-navigation`。基线传输文件已移除；本记录不表示远端已推送或集成。

## 可用入口与实际语义

```sh
kepub toc BOOK.epub --json
kepub inspect BOOK.epub --section navigation --json
kepub inspect BOOK.epub --section references --json
kepub inspect BOOK.epub --section references --resource '书/Text/-first.xhtml' --direction incoming --json
kepub inspect BOOK.epub --section references --resource '书/Text/-first.xhtml' --direction outgoing --json
```

- `toc` 与 `inspect --section navigation` 共用 `app.Inspect`，除 envelope 的 command/requestId 外，data 完全相同。目录树绝不由 spine 合成，不重排或注入 spine。EPUB3 按 manifest 的独立 `nav` token 选择 XHTML，按正确命名空间的 `epub:type` 独立 `toc` token 选择目录；EPUB2 按 spine 的 `toc` ID 选择 NCX。歧义、缺失、类型错误都不回退为“第一个文件”。
- 导航返回 source、format、status、parserVersion、递归 entries 和 diagnostics。分组 span 的 href/target/exists 为 null。标签按混合文本的文档顺序读取并折叠空白。NCX 保持 navPoint 文档顺序，不用 playOrder 替代结构，不将 navMap 与 pageList/navList 混合。
- 引用边含 source、结构 location、syntax、原 URL 字符串 href、target.bookPath/fragment/query/external、status、fragmentStatus、parserVersion。XML 属性已按 XML 规则解码实体；不把这个只读索引称为原文件的可写字节区间。Href 的 percent encoding、query 和 fragment 拼写保留，目标路径/fragment 只解码一次。OPF IDREF 边保留原 ID 字符串，通过 manifest 解析目标。
- `--resource` 是精确 BookPath，不是 URL，不作大小写或 Unicode 折叠。只传 resource 时返回双向边（direction=both），显式 direction 只允许 incoming/outgoing，且必须有 resource。不存在的 BookPath 也可查询，包括缺失目标；空边不意味着引用不存在。
- 过滤只改变 edges，完整 archive 范围的 coverage/diagnostics 保留，防止其他未知资源中的入站引用被过滤掉。coverage 按文件和语法稳定排序，edges 按文件和解析顺序输出，重复构建 JSON 一致。
- envelope 的 `ok:true`、退出 0 仅表示只读查询完成。坏 nav/章节可在成功查询内报告 blocked/partial；container/OPF 无法建立 M1-A 基础模型时仍返回原错误 envelope。无效过滤参数在打开文件前返回退出 2；文件 I/O 失败返回退出 6。pack/validate/编辑/GUI 仍未开放。

## 逐语法 coverage 与诊断边界

每条 coverage 含 resource、syntax、complete/partial/blocked、reasons 和 parserVersion。顶层 references status 仅汇总**提取覆盖范围**，不汇总 EPUB 合规，也不是安全改名/删除许可。存在 missing target/fragment 时，某个已完整提取的语法仍可 complete；诊断独立报告内容问题。

| 语法 | 本轮范围 |
|---|---|
| container.rootfile、opf.manifest、opf.spine | 原 full-path/href/idref 与目标；只解释选中的 OPF |
| opf.href / opf.idref | href/refines、toc/fallback/fallback-style/media-overlay/handler ID 目标 |
| nav.href / ncx.src | XHTML nav 中的 href；NCX 的 src（目录查询只返回 TOC/navMap） |
| xhtml.href / xhtml.src | 严格 XML 中的未限定名属性，不用 HTML 容错补树 |
| svg.href | SVG href/xlink:href，包含 XHTML 中内嵌 SVG |
| css.url / css.import | 不含 CSS escape 的字面 `url()`、`@import "..."`、`@import url(...)`；跳过注释和普通字符串中的伪 URL |
| css.grammar / inline-style | 全 CSS 语法始终 partial；内联属性、style 元素及列明 SVG presentation 属性用同一 CSS 子集；escape/坏 token 使相应 literal coverage 也 partial，非 UTF-8/含 NUL 则 blocked |
| xml.ids / fragment | 普通 id/xml:id 索引；报告缺失/重复/歧义，同元素相同 id+xml:id 不算两个目标。CFI/XPointer 等非 ID 片段及不可解析目标明确 not_checked/partial |
| 未实现语法 | script（含 manifest scripted、事件属性、javascript URL）、srcset、SMIL、SVG 动画、XML processing instructions、meta refresh 等 blocked；未知命名空间和 data URL 内部 payload 明确不完整 |
| 未登记/未知资源 | 遍历 archive，不只遍历 manifest；可按扩展名尝试 XHTML/CSS/SVG/NCX，但仍保留 unmanifested-resource partial；其他未知字节资源 blocked。声明的栅格图/字体仅视为不含出版 URL 语法的叶资源，不校验二进制有效性 |

保留 M1-A 的安全 staging、路径检查及原字节。XML/CSS 单资源解析上限 8 MiB；XML 保留 128 层/200,000 token 限制，并新增累计文本/位置索引 32 MiB 限制，避免混合标签索引放大内存。xml:base、HTML base、DTD、UTF-16 等不支持输入不作猜测解析。解析失败的文档不泄露“部分边却 complete”的图，其他可解析文档仍返回结果。外部 URL 只分类，绝不联网或执行。

## 已实际执行的验证

```sh
git diff --check
go test -count=1 ./...
go test -race -count=1 ./...
go vet ./...
go test -count=1 ./cmd/kepub -run TestCLIProcessSmoke -v
go test ./internal/references -run '^$' -fuzz=FuzzCSSLiteralURLs -fuzztime=5s
go test ./internal/publication -run '^$' -fuzz=FuzzXML -fuzztime=5s
go test ./internal/bookpath -run '^$' -fuzz=FuzzResolve -fuzztime=3s
CGO_ENABLED=0 GOOS=darwin GOARCH=arm64 go build -o /tmp/kepub-m1b1-darwin-arm64 ./cmd/kepub
file /tmp/kepub-m1b1-darwin-arm64
go list -deps -f '{{if not .Standard}}{{.ImportPath}}{{end}}' ./cmd/kepub
```

全部通过。单测/race 包含 M1-A 原回归；vet 与 diff --check 退出 0。真实 CLI smoke 编译并启动独立二进制，九次调用全部匹配预期：info/manifest、EPUB3 toc、EPUB2 toc、navigation、outgoing、incoming 退出 0；缺失 resource 的 direction 退出 2；缺失输入文件退出 6。每次 stdout 恰好一个 JSON envelope、stderr 为空。outgoing 两条、incoming 七条边由 fixture 独立推导并断言，均保留 partial coverage/diagnostics；原 ZIP 调用前后逐字节一致。

Fuzz 实际执行计数：CSS 124,789；XML 55,964；BookPath 80,944，均 PASS。CSS fuzz 根据输入生成合法字面 URL，同时植入注释/字符串伪 URL，独立断言原 href、目标路径和片段，而不只检查是否崩溃。这只是短时有界探索，不是完整语法或安全证明。

主要样本：EPUB2/3、深层 OPF、三层不对称目录、nav 不在 spine、manifest/spine/目录不同顺序、混合标签与 `&amp;`、中文空格/百分号、跨目录/同文档/query/片段、大小写错误、缺失目标/ID、重复 ID、坏 XML/DTD/base、缺失/多重导航、unknown vocabulary、script/CSS/SMIL/srcset。导航/引用测试逐一核对 archive 中原资源字节；CLI 还检查 `--` 与短横线/中文/空格输入名。多 rootfile 选择、解包、路径碰撞等现有回归保留。

依赖仍只有项目自身、Go 标准库、已有 `x/sys` 和 `x/text`；未修改 go.mod/go.sum/setup。Mac 交叉编译输出为 `Mach-O 64-bit arm64 executable`，临时二进制已清理。

## 未证明与后续门槛

- **未运行 Apple Silicon Mac 实机**；交叉编译不证明 macOS 文件系统、GUI/WKWebView、签名、公证或打包体验。
- 没有 EPUBCheck、完整 EPUB/OCF/XML/CSS 合规校验、渲染、外部链接可达性、pack 或任何出版物修改。图中 complete 仅指所报告语法已完成提取；未来 mutator 仍需自己的明确支持子集与 preflight，不能直接把该字段当编辑授权。
- 导航只覆盖 toc/navMap；不重建目录、不验证 NCX playOrder、不认证可访问性。导航 exists 仅表示精确文件存在，片段验证要看 references 的 fragmentStatus。
- 继承 M1-A 的 UTF-8 XML/ZIP 输入边界；目录输入、UTF-16、DTD、xml:base、远程 manifest href 等没有在本批扩展。CSS 是明确保守的提取器，不是完整 CSS parser；语法位置不供保真写回。
- full registry schema/help 自动生成、持久图缓存/输入树哈希绑定、取消/超时及大型真实出版物性能验收仍属于后续工作。本轮未改工作区/Agent 原型或根 README/方案，集成线程负责更新总体交付状态。
